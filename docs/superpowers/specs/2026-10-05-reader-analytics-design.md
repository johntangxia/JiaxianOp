# 读者侧分析 · 设计方案

- 日期：2026-10-05
- 状态：待实施（实施计划见 [读者侧分析](../plans/2026-10-05-reader-analytics.md)）
- 前置依赖：[数据基础](2026-10-05-data-foundation-design.md)（加入社区日期、留存分型、沉默读者模拟）和[行为数据扩充](2026-10-05-behavior-data-design.md)已实现。

## 1. 目标

前面的分析都站在内容和频道一侧；这一份站在**读者**一侧，回答：社区有多少人在用、新加入的人留不留得住、新人有没有被激活、有哪些人只看不互动。

## 2. 口径

- **活跃**：当天在 `active_action_log` 里有任何记录（登录、浏览、点赞、评论、转发、收藏、发帖）。
- **成员**：加入社区日期（`community_join_date`）不晚于当天的员工；加入日期为空的旧数据视为一直是成员。活跃率 = 活跃人数 / 成员数。
- **DAU / WAU / MAU**：截至区间结束日，当天 / 近 7 天 / 近 30 天（含当天）的去重活跃人数。黏性 = 近 30 天日均 DAU / MAU。
- **读者角色**（周期内，只统计周期结束时已是成员的员工；互动指点赞、评论、转发、收藏）。判定顺序固定，一个人只属于一类：
  1. **创作者**：周期内发过帖；
  2. **互动者**：没发帖，但互动过；
  3. **沉默读者**：只有浏览，没发帖也没互动；
  4. **仅登录**：有行为记录但只有登录，没有浏览；
  5. **不活跃**：周期内没有任何行为记录。

## 3. 四块内容

### 3.1 活跃与增长 `GET /api/readers/activity?from&to&granularity`
按周期（DAY/WEEK/MONTH）返回：活跃人数（周期内去重，所以日=DAU、周=WAU、月=MAU）、新增成员数、期末成员数、活跃率；以及汇总：截至 `to` 的 DAU（`to` 当天）、WAU、MAU、黏性、成员总数。

### 3.2 留存同期群 `GET /api/readers/retention?granularity=WEEK|MONTH&from&to&periods=N`
同期群 = 按加入周/加入月分组（加入日期落在 `[from, to]` 内的成员）。第 k 列 = 加入后第 k 个周期里至少活跃过一天的人占同期群的比例（k = 0 是加入当期）。数据尚未覆盖的周期（超过数据最后一天）为空，不画成 0。`periods` 默认 8（周）/ 6（月），最多 12。历史开始前加入的老成员不在任何同期群里（页面注明）。

### 3.3 激活漏斗 `GET /api/readers/funnel?from&to`
对象：加入日期在 `[from, to]` 内的成员。步骤（相对加入日 0 点）：加入 → 7 天内首次浏览 → 7 天内首次互动 → 30 天内首次发帖 → 加入后第 2 周（第 7–14 天）仍活跃。每步返回人数、相对上一步和相对加入的转化率。窗口天数是常量。

### 3.4 读者分层与沉默读者
- `GET /api/readers/segments?from&to`：五类角色的人数和占比，以及成员总数。
- `GET /api/readers/lurkers?from&to&dept&limit&offset`：沉默读者名单（**展示姓名**）：姓名、部门、加入日期、浏览次数、活跃天数、最近活跃日；按浏览次数从高到低（同数按员工 id）；`dept` 可选筛选；`limit` 1–100（默认 20），`offset` ≥ 0；返回总数。

## 4. 页面
`/readers`"读者分析"，四个标签页：活跃与增长（顶部 DAU/WAU/MAU/黏性卡片 + 趋势图）、留存（热力表）、激活漏斗（横向漏斗图 + 表）、读者分层（占比图 + 沉默读者名单，点姓名进博主页）。日期范围默认 PV 数据最后一天往前 180 天，和驾驶舱一致。

## 5. 后端结构
新增 `reader` 包：`ReaderQueryRepository`（聚合查询；活跃日以 (员工, 日) 去重行取出，周期聚合在 Java 里做）→ `ReaderService`（周期、同期群、漏斗、分层的装配）→ `ReaderController` + 异常处理。区间两端含，日期范围最长 366 天；`to` 不能早于 `from`；非法参数 400 + 一句文字说明。

## 6. 演示数据
同期群每个周期只有几个人时留存曲线没法看。演示默认员工数从 50 提到 200（`scripts/seed-demo.sh` 和模拟器控制台的默认值）；已有测试的参数不变。

## 7. 测试
- 纯函数：周期归并、同期群留存（含数据未覆盖的周期为空）、漏斗转化率、角色判定顺序。
- 仓库：2019 年夹具逐项核对（活跃日、成员数、新增、角色、沉默读者名单与筛选分页、漏斗窗口边界）。
- 服务与接口：装配、校验、形状。
- 端到端：回填后沉默读者在名单里全部没有互动/发帖、同期群大小之和 = 区间内加入的成员数、DAU ≤ 成员数。
- 前端：展示工具函数和图表配置的单元测试；`npm run build`；浏览器走查。

## 8. 明确不做的范围（Out of Scope）
- 部门渗透率、召回任务和提醒（计划 16）。
- 读者兴趣画像、个人读者详情页、名单导出。
