# Cloudflare Pages 静态演示版设计

## 目的与边界

在公网展示现有 Vue 看板的主要指标口径和交互，不连接 Spring Boot、OpenGauss、Redis 或 Kafka。公开版展示从本地模拟服务只读提取并脱敏的固定快照，保留系统管理以外的所有页面：总览、访问流向、频道及下钻、频道竞赛、对比、读者、创作者、用户及用户 360、增长闭环、积分排行榜和 KOL。日期、统计结果和建议均为模拟数据；快照不自动更新。

用户 360 仅提供有限个完全匿名的模拟人物；增长任务及告警状态支持浏览器本地操作，清除本地存储会恢复初始状态。公开版不提供完整员工名单、服务端任务协作或系统管理。列表导出仅导出发布的演示样本。公开版不保留任何 `/api` 网络请求或可操作的管理端点。原有内网版仍按默认 `npm run build` 构建。

## 实现选择

选择现有 Vue 页面加浏览器内的模拟 API 适配层，数据从打包的 JSON 导入；静态路由只移除系统管理。比较过两种方式：另建少数静态视图无法保留用户要求的全部功能；把 Spring Boot 改成 Pages Functions 仍需移植复杂分析逻辑且不符合轻量、无后端约束。适配层会对已发布样本做本地筛选、排序与分页，日期只接受预先计算的演示窗口；不支持的组合明确报错，不冒充实时统计。

## 数据与安全

提取脚本只调用允许的只读分析接口，以显式字段白名单导出聚合结果和有界关联样本。博主、用户和账号名称使用演示编号，用户 360 只保留少量脱敏示例；原有模拟器记录编号仅作为静态路由键，不导出真实身份标识、账号登录信息或后台配置。用户 360 的近期事件只保留时间和行为类别，关联对象编号被移除。提交前检查快照内容与产物中无原始个人名称和 `/api` 请求。

## 部署

`npm run build:demo` 设置 `VITE_STATIC_DEMO=1`，Vite 输出 `frontend/dist`。`frontend/public/_redirects` 为 Pages 深层路径提供 SPA 回退。Cloudflare Pages 项目根目录为 `frontend`，构建命令 `npm run build:demo`，输出目录 `dist`。构建过程不调用本地服务；快照更新是开发时显式执行的只读操作。
